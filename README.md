**# 6T-SRAM-Cell-Design-and-Characterisation-using-Cadence-Virtuoso**

6T-SRAM cell is a fundamental memory element used for storing one bit of data using six MOS transistors.  
Designed the 6T-SRAM schematic using Cadence Virtuoso. Analyzed read, write, and hold operations of the SRAM cell. 
Evaluated static noise margin (SNM) for cell stability. 
Designed and verified the physical layout using DRC and LVS.
